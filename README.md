# 🧩 Problem-Solving Approach

For every problem, I aim to follow these steps:

1. **Understand:** Identify the problem requirements and constraints.
2. **Brute Force:** Think of the simplest correct approach.
3. **Optimize:** Look for a better algorithm or data structure.
4. **Analyze:** Calculate time and space complexity.
5. **Implement:** Write a clean Java solution.
6. **Dry Run:** Trace the code using sample inputs.
7. **Test:** Check edge cases and boundary conditions.
8. **Revise:** Revisit important problems to strengthen understanding.

---

# ⏱️ Complexity Analysis

Every algorithm should be evaluated for its time and space requirements.

Common time complexities:

| Complexity | Description  | Example                         |
| ---------- | ------------ | ------------------------------- |
| O(1)       | Constant     | Array element access            |
| O(log n)   | Logarithmic  | Binary Search                   |
| O(n)       | Linear       | Array Traversal                 |
| O(n log n) | Linearithmic | Merge Sort                      |
| O(n²)      | Quadratic    | Basic Bubble Sort               |
| O(2ⁿ)      | Exponential  | Some recursive subset solutions |
| O(n!)      | Factorial    | Generating all permutations     |

Actual complexity depends on the specific implementation and input.
